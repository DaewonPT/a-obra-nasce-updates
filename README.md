# A Obra Nasce — Android builds

**A Obra Nasce** is a puzzle game about art and the people who make it: each level is a painting broken into pieces, and when it is whole again a tiny Fernando Pessoa reads a line about art. Portuguese only, for now.

Every version is published here as a [release](https://github.com/DaewonPT/a-obra-nasce-updates/releases) with the APK attached. The file name carries the version (`AObraNasce_vX.Y.Z.apk`), so the newest download is easy to spot.

## Install

1. On the phone, open the [latest release](https://github.com/DaewonPT/a-obra-nasce-updates/releases/latest) and download `AObraNasce_vX.Y.Z.apk`.
2. Open the file and tap **Install** (allow the browser to install apps if Android asks).

## Updates

From version 0.1.2 the game checks this page when it starts. When a newer release exists, the menu shows a gold **Versão nova** button: download the APK and install it over the old one. Progress is kept.
